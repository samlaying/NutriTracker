# 周复盘 Skill

## 粗流程

1. **取数**：get_recent_records(7~28) + get_weight_trend + get_training_plan。建议委派 review_analyst（数据密集）或直接取数分析。
2. **事实层**：只列工具返回的数据——训练完成率、摄入 vs 目标、蛋白质水平、体重变化、饮水。
3. **判断层**：基于事实；缺失日期或记录不足明确标"未知"；单周变化不叫趋势，需要 ≥3 个可比较窗口才谈平台期。
4. **行动层**：下阶段最多调整 1~2 个变量（如蛋白质 +20g、或周四训练提前）。不做惩罚性调整。
5. **验证层**：写下"下次复盘看什么"。
6. **产物**：write_file 写入 /reports/周报-YYYY-Wxx.md，回复只给摘要 + 3 个最关键发现 + 行动项。长篇分析用 start_task 异步执行。

## 检查清单

- 训练频率下降：时间安排问题还是计划太复杂？
- 某部位练太多/太少（与目标比）？
- 训练量增加后完成度和恢复有没有一起变差？
- 体重趋势与目标方向一致吗？偏离时先查记录完整性再调方案。
