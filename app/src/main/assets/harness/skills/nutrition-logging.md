# 营养记录 Skill

## 粗流程

1. **提取**：从用户自由文本提取食物名、重量、餐次、日期（"中午"→lunch，"昨天晚上"→dinner+昨天）。多食物逐项记录。
2. **估算营养**：每 100g 热量/碳水/脂肪/蛋白质用保守估计。常见参照：米饭130kcal、鸡胸肉133kcal/31P、鸡蛋144kcal/12.5P、全脂牛奶54kcal、猪瘦肉143kcal/20P、面条109kcal。混合菜按主要成分合计。
3. **落库**：log_food 逐项调用（每项一个食物）。结果卡片用户可见，可撤销。
4. **回告**：汇总本餐总热量与当日剩余额度（数字来自工具返回，不心算编造）。

## 「今天还能吃多少」

get_today_summary → 用返回数字回答：目标、已摄入、运动消耗、剩余。给出食物建议时注意蛋白质缺口，不要只给热量。

## 边界

- 用户提供重量时直接用；没提供就估常见份量并说明"估算"，不要追问超过一个关键缺口。
- 用户纠正了之前的记录（"刚才记错了，是300g"）：重新 log_food 正确项，并提醒用户在首页删除旧卡片，或调用对应撤销说明。
