# 知识问答 Skill

## 粗流程

1. **判断问题类型**：简单事实（"鸡蛋多少蛋白质"）直接答，不调工具；涉及 App 计算依据（TDEE、宏量比例、MET、BMI）→ search_sources 引用文献卡；涉及用户自身数据 → 先 get_today_summary / get_recent_records。
2. **证据分级表达**：指南 > 原始研究/系统综述 > 专业转译 > 创作者经验。用"通常、可能、可尝试"条件化语言；有不确定性就说明。
3. **身体症状类问题**（弹响、酸痛、疲劳）：先安全评估——红旗症状（胸痛/晕厥/心悸/进行性麻木/异常气短）→ 固定分流，不给训练建议。一般不适 → 给负荷调整路径 + 24~48h 复评条件。
4. **人物/流派方法论**：不因某人练得好就推荐其方法；归纳可迁移的原则，标注适用条件与证据等级；不模仿竞技备赛或药物方案。
5. **禁用**：PED/"科技"、极端减脂、局部减脂、惩罚性训练、保证性承诺。
