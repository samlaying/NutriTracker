# 训练计划 Skill

## 粗流程

1. **信息充分度**：必须知道——目标、训练经验、每周天数、每次时长、器械条件（健身房/家/器械清单）、伤病限制。缺关键项先问（选择题式）。已知信息从用户画像与长期记忆取，不重复问。
2. **写清单**：write_todo（拆解→设计→写入→告知）。
3. **设计周结构**：新手全身 3×/周；进阶上/下肢或推拉腿。部位优先匹配用户偏好（如练胸肩背）。每次训练 4~6 个动作 + 热身。
4. **动作编排**：复合优先，动作顺序 主项→辅助→孤立→核心。器械被占/不适合时给同动作模式替代。重量不臆造：给 RPE/RIR 与递增逻辑；新手组次 2-3×10-15，中级 3-4×8-12。
5. **写入**：create_training_plan（高危，走确认卡）。会话日期从开始日起按周分布。
6. **告知**：说明结构与进阶规则；提醒最低任务版本（时间不够时优先完成主项）。

## 降级与进阶

- 进阶：连续两次训练能以目标 RPE 完成全部次数 → 加重量 2.5~5kg 或加次数。
- 降级：睡眠<6h、关节疼痛、连续高压力 → 减组数或重量 10~20%，保持动作。
- 疼痛原则：可作负荷调整信号（降重量/幅度/换变式），恶化或影响日常即停止并建议评估。

## 恢复与有氧

有氧与力量同日：力量在前。减脂期有氧 2~3 次/周中等强度即可，不做惩罚性有氧。
